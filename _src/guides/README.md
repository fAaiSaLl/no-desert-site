# مقالات موقع «لا للتصحر»

الموقع العام: https://faaisall.github.io/no-desert-site/ (مستودع fAaiSaLl/no-desert-site، فرع main، GitHub Pages).
المصدر كله في هذا المستودع داخل `_src/`. البناء من جذر المستودع: `python3 _src/build.py`

لغتين فقط:
- `ar/` عربي فصحى لكل العرب (الرئيسية /)
- `en/` English (/en/)

كل مقال ملف `<slug>.html` (slug بحروف لاتينية)، أوله:

    <!-- title: العنوان -->
    <!-- description: جملة لنتائج Google (أقل من 160 حرف). -->
    <!-- date: 2026-11-24 -->

بعدها جسم المقال HTML فقط (p, h2, h3, ul, ol, table, strong, div.box, div.sources).
بدون أدوات تفاعلية أو حاسبات (طلب المالك).
المولّد يضيف التصميم وزر التحميل والروابط وsitemap.

قواعد الكتابة:
- سؤال واحد حقيقي يبحث عنه الناس، والجواب في أول فقرة ("باختصار:").
- كل رقم صحي له مصدر موثوق (Mayo Clinic، WHO، CDC، FDA، EFSA، وزارة الصحة السعودية) في `<div class="sources">` آخر المقال.
- ممنوع: "٨ أكواب للكل" كحقيقة، "الماء يخسس/يحرق الدهون"، "يعالج/يقي من"، "القهوة تسبب جفاف"، أي ادعاء طبي بدون مصدر، تقييمات أو أرقام مخترعة.
- معادلة التطبيق (٣٣ مل/كغ + النشاط) تُكتب "تقدير مبدئي"، ونسب احتساب المشروبات "طريقة التطبيق، مو أرقام طبية".
- ميزات التطبيق الحقيقية فقط: الشخصيات (المدرب الصارم، الوضع المحترم، راعي الطقطقة، المذيع العاجل)، أزرار كوب/قنينة/شاي/قهوة/عصير/طاقة، وضع رمضان (من المغرب لقبل الفجر)، تنبيه الحر ٣٨° حسب المدينة، الإحصائيات والشارات، الودجت، تسجيل الكوب من الإشعار. التطبيق للآيفون والآيباد فقط، ومو متاح في الصين ودول الاتحاد الأوروبي.
- ٥٠٠ إلى ١٠٠٠ كلمة، بدون حشو كلمات.
